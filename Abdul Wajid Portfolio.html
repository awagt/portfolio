Tools I built

In use at The Blue Group

When a workflow costs the team time, I don't wait for an IT ticket. These are working tools I designed and built for our warehouse, dispatch and management teams.

REFSTO-SCAN

Stock Transfer Order scan tool

A browser-based barcode scanner for warehouse stock transfers. Each scan writes back to Google Sheets live, with a beep for good and bad scans, and alerts for over-scans, wrong-STO items and barcodes that belong to another transfer. It replaced a fragile Excel workbook.

In daily useHTML · Apps Script · Google Sheets · Web Audio
REFSPC-DSP

Dispatch & returns tracker, Sports Corner

Batch scanning of outgoing orders, delivery agent assignment, a returns module and printable PDF manifests. Imports Magento order exports, keeps an audit log, and has Admin, Staff and Guest roles.

In daily useFirebase · Magento import · GitHub Pages
REFSFL-DSP

Dispatch & returns tracker, Sports For Less

The same feature set rebuilt for the second entity, using Google Sheets tabs as the database so the team can see and edit records directly.

In daily useApps Script · Google Sheets · GitHub Pages
REFMGT-RPT

E-commerce management dashboard

Weekly and monthly reporting across both entities: gross orders, net sales, AOV, cancellation, invoice and refund rates, COD vs online payment, and an order funnel. Syncs from a Google Sheet every five minutes and prints as a clean light-theme PDF.

ManagementChart.js · SheetJS · Apps Script
REFENDOW

Endow Crafts website
